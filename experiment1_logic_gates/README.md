# Logic Gates Experiment
Aim:
Implementing  AND/NAND/NOR logic gates using ESP32. 

Objective:
• To understand the working principle of basic logic gates 
• To verify the truth table of AND, NAND and NOR, logic gates using ICs. 
• To learn the interfacing of logic gates with ESP32 
• To interpret the output through the OLED display module

Components Used:
ESP32 
SSD1306 OLED Display 
4011 
74HC08 
74HC02 
LEDs  
External Power Supply 
Jumper Wires 
Breadboard
Micro-USB cable 

Software Required 
• Arduino IDE 
• ESP32 Board Package 
• Adafruit SSD1306 Library 
• Adafruit GFX Library 


Procedure:
1. Connected logic gate IC on breadboard.
2. Applied different input combinations.
3. Observed output using LEDs.

Observation:
Outputs matched the expected truth table of the logic gates.
